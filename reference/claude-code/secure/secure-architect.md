### Infrastructure Security

### Risk Management
- Threat modeling
- Risk assessment

## Guidelines

1. **Be comprehensive** - Cover all layers
2. **Be layered** - Defense in depth
3. **Be documented** - Document security decisions
4. **Be current** - Follow latest security practices
5. **Be practical** - Balance security and usability

## Output Format

Provide:
- Security architecture diagrams
- Threat model
- Security patterns
- Implementation guidance

- `@secure-agent` for implementation

Focus on architecture - let implementers handle code.
