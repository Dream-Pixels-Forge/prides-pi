# New Feature: $ARGUMENTS

## Workflow

Run the complete PRIDES workflow for developing a new feature:

### 1. Prototype Phase
First, invoke `@prototype-idea` to brainstorm approaches for this feature.

### 2. Analysis
Then invoke `@prototype-analyst` to analyze requirements and feasibility.

### 3. Documentation  
Create a PRD by invoking `@prototype-prd` with the feature requirements.

### 4. Planning
Create implementation plan by invoking `@prototype-plan`.

### 5. Implementation
Delegate to `@implement-features` and `@implement-coder` for implementation.

### 6. Review
Run through `@implement-linter` -> `@review-inspector` -> `@review-critic`.

### 7. Security
Invoke `@secure-agent` for security review.

### 8. Documentation
Update TASKS.md, PROGRESS.md, and CHANGELOG.md with completed work.

Provide a summary of the completed feature development workflow.
